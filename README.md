# Student Deadline Tracker

**Призначення:** Застосунок для відстеження дедлайнів лабораторних та модульних робіт.
**Користувач:** Студент, якому потрібно контролювати свої успіхи та борги з навчання.
**Основні сценарії:** Створення завдання, прив'язка його до певного курсу, фільтрація незданих робіт.
**Сутності:** 
1. `Assignment` (навчальне завдання)
2. `Course` (навчальна дисципліна, яка містить список завдань)

## Реалізація конструкцій Swift
- **struct, class, protocol, enum, колекції**: реалізовані у файлі `Models.swift`.
- **Безпечне розгортання (if let) та сценарії**: реалізовані у файлі `ViewController.swift` у методі `viewDidLoad()`.

## Обґрунтування вибору типів (struct vs class)
- `Assignment` реалізовано як `struct`, оскільки це проста модель даних (Value Type), яка передається копіюванням і не має власного життєвого циклу чи складного спільного стану.
- `Course` реалізовано як `class` (Reference Type), оскільки це об'єкт, який керує колекцією завдань. Нам потрібно, щоб зміни в курсі (наприклад, додавання нового завдання) відображалися в усіх посиланнях на цей об'єкт.
